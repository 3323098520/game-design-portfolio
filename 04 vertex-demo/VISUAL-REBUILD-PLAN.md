# VERTEX Demo 视觉重构计划

## 现状判断

- 五关流程、三类武器、敌人、闸门、计分和本地存档已经接入原策划数据，继续沿用。
- 当前主要问题是呈现层：光照过曝、材质没有层级、场景重复、掩体缺少功能辨识、枪械与手臂像积木、敌人远距离轮廓不清。
- 发布入口仍指向旧版单文件 Demo，完成验收后需要把新版提升为正式入口。

## 本轮范围

1. **场景美术**：建立深色结构、暖灰地面、青色导视、橙色危险标识的统一色彩体系；增加跑道标线、训练模块、顶灯、隔离栏、远景建筑和功能标牌。
2. **枪械与手臂**：重做手套和双臂轮廓，让手枪、步枪、霰弹枪具备不同尺寸、持枪姿态、机械结构和动作幅度。
3. **敌人与反馈**：加强头部、核心、装甲和敌人类型的色彩辨识；改善枪口焰、弹壳、命中粒子和受击提示的可读性。
4. **界面**：把白色宣传页改成训练终端风格；保留少量常驻 HUD，不增加与策划无关的系统。
5. **入口与发布**：验证通过后，用新版替换 `04 vertex-demo` 的公开入口，保留旧实现文件作为历史备份。

## 验收标准

- 自动化规则测试全部通过，五关数据仍来自原 JSON。
- 1280×720 下菜单和战斗画面无溢出，枪械不横向朝向玩家，场景不过曝。
- WASD 仍按镜头朝向移动；掩体阻挡子弹与玩家；三把枪的射速、后坐、装填和反馈保持可区分。
- 本地根入口与 GitHub Pages 根入口均能直接进入新版，不再显示 HTML 源码。
- 不声称未经人工完成的手感测试或性能数据。
