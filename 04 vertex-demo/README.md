# 顶点射手 VERTEX · 可玩 Demo

这是《顶点射手》策划案对应的 3D 第一人称浏览器 Demo。它用一个可完成的训练关卡验证移动、瞄准、武器选择、敌人反制、撤离、评分和快速重试。

## 运行方式

直接双击 `index.html` 即可开始。也可以在 GitHub Pages 或任意静态服务器中打开。

## 操作

- `WASD`：移动
- 鼠标：瞄准与射击
- `1 / 2 / 3`：切换手枪、突击步枪、霰弹枪
- `R`：换弹
- `Shift`：疾跑
- `Esc`：释放鼠标并暂停

## Demo 范围

- 三波训练目标：巡逻机器人、突击机器人、空中无人机
- 三把定位不同的武器：手枪、突击步枪、霰弹枪
- 一条中央主路线和一条左侧翼路线，掩体交错摆放
- 使用 CC0 枪械、角色、空间站场景和第一人称手臂素材
- 枪口火焰、后坐、弹壳、命中、受击、击杀和换弹反馈
- 步枪连续抛壳，霰弹枪有更强后坐和泵动表现
- 每波敌人入场后先等待数秒，给玩家观察路线的时间
- 实体掩体碰撞：角色不能穿过，子弹会被遮挡
- 训练场环境、角色外形、武器音色和战斗氛围音
- 到达撤离点后的 S/A/B/C/D 评级
- 武器参数和敌人参数存放在 `data/vertex-config.json`

这是一个可试玩的玩法竖切片，重点展示策划案如何落成可操作、可验证的战斗体验；它不是完整商业游戏。

第三方美术来源与许可见 `ASSET-LICENSES.md`。
