# 顶点射手 VERTEX · 可玩 Demo

这是《顶点射手》策划案对应的 3D 第一人称浏览器 Demo。五场短关卡从手枪、步枪、空中目标、近战爆发逐步过渡到综合认证，用来验证移动、瞄准、武器选择、敌人反制、撤离、评分和快速重试。

## 运行方式

建议直接使用作品集里的“在线试玩 Demo”。本地运行需要静态服务器，例如在仓库根目录执行 `python -m http.server 8765`，再访问 `http://127.0.0.1:8765/04%20vertex-demo/`。

## 操作

- `WASD`：按当前镜头朝向移动
- 鼠标：瞄准与射击
- `1 / 2 / 3`：切换手枪、突击步枪、霰弹枪
- `R`：换弹
- `Shift`：疾跑
- `Space`：跳跃
- `Esc`：释放鼠标并暂停

## Demo 范围

- 五关训练流程：新兵报到、步枪认证、空中目标、近战爆发、顶点认证
- 三把定位不同的武器：手枪、突击步枪、霰弹枪
- 主路线与侧翼路线并存，掩体、闸门和训练分区会改变交火位置
- 原创训练中心标题画面，以及实时绘制的低多边形训练场、枪械、手臂和机器人
- 枪口火焰、后坐、弹壳、命中、受击、击杀、换弹与霰弹枪泵动反馈
- 实体掩体碰撞：角色不能穿过，子弹会被遮挡
- 到达撤离点后的 S/A/B/C/D 评级，成绩按时间、命中和生存计算
- 设置与成绩保存在当前浏览器

这是一个可试玩的玩法竖切片，重点展示策划案如何落成可操作、可验证的战斗体验，不等同于完整商业游戏。

正式入口使用 `rebuild/` 下的规则与视图模块；关卡和数值读取 `01 PORTFOLIO_VERTEX/data/` 中的原始 JSON。
