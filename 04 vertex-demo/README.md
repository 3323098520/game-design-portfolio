# 顶点射手 VERTEX · 可玩 Demo

这是《顶点射手》策划案对应的浏览器 Demo，用一个可完成的训练关卡验证核心循环：移动、瞄准、武器选择、敌人反制、评分和快速重试。

## 运行方式

直接双击 `index.html` 即可开始。也可以在 GitHub Pages 或任意静态服务器中打开。

## 操作

- `WASD`：移动
- 鼠标：瞄准与射击
- `1 / 2 / 3`：切换手枪、突击步枪、霰弹枪
- `R`：换弹
- `Space`：冲刺
- `P`：暂停

## Demo 范围

- 三波训练目标：巡逻机器人、突击机器人、空中无人机
- 三把定位不同的武器
- 白盒训练场与掩体
- 命中、受击、击杀和换弹反馈
- 实体掩体碰撞：角色不能穿过，子弹会被遮挡
- 训练场环境、角色外形、武器音色和战斗氛围音
- 到达撤离点后的 S/A/B/C/D 评级
- 武器参数和敌人参数存放在 `data/vertex-config.json`

这是一个浏览器原型，重点验证玩法和战斗节奏，不代表最终美术品质或完整商业版本。
