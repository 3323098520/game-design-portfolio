# 顶点射手 VERTEX · 可玩 Demo

这是《顶点射手》策划案对应的 3D 第一人称浏览器 Demo。它用一个可完成的训练关卡验证核心循环：移动、瞄准、武器选择、敌人反制、撤离、评分和快速重试。

## 运行方式

直接双击 `index.html` 即可开始。也可以在 GitHub Pages 或任意静态服务器中打开。

## 操作

- `WASD`：移动
- 鼠标：瞄准与射击
- `1 / 2 / 3`：切换手枪、突击步枪、霰弹枪
- `R`：换弹
- `Shift`：疾跑
- `Esc`：释放鼠标并暂停

## Demo 范围

- 三波训练目标：巡逻机器人、突击机器人、空中无人机
- 三把定位不同的武器
- 3D 训练场与实体掩体，角色和射线遵循同一套遮挡规则
- 命中、受击、击杀和换弹反馈
- 实体掩体碰撞：角色不能穿过，子弹会被遮挡
- 训练场环境、角色外形、武器音色和战斗氛围音
- 到达撤离点后的 S/A/B/C/D 评级
- 武器参数和敌人参数存放在 `data/vertex-config.json`

这是一个作品集级玩法竖切片，重点展示策划案如何落成可操作、可验证的战斗体验；它不是完整商业游戏。
