# VERTEX · GDD 重构版

这是一份独立的新 Demo，不覆盖上一版。原始策划案与数值文件保持不变。

## 试玩

线上入口：<https://3323098520.github.io/game-design-portfolio/04%20vertex-demo/rebuild/?v=20260906-1>

使用电脑 Chrome / Edge，点击开始训练。默认采用鼠标锁定；若浏览器不允许，在暂停页选择“窗口兼容模式”，按住右键拖动观察，左键射击。

WASD 移动，右键瞄准，左键射击，R 换弹，1/2/3 切枪，Shift 冲刺，空格跳跃，Esc 暂停。
初始只配发手枪，第二关配发步枪，第四关配发霰弹枪。通关解锁下一关，成绩仅保存在当前浏览器。

本地运行：在整个作品集仓库根目录执行 `python -m http.server 8765`，打开 `http://localhost:8765/04%20vertex-demo/rebuild/`。不要直接双击 HTML；也不要只拷贝本目录而遗漏上级的原始 JSON 和音频。

## 与策划案的对应

| 内容 | 实现 |
|---|---|
| 原始数值 | 直接读取 `01 PORTFOLIO_VERTEX/data` 中的 player、weapons、enemies、levels，无另设伤害表 |
| 五关认证 | 13 / 12 / 17 / 16 / 13 个敌人，按原节拍表分区；第五关清场后 90 秒撤离 |
| 三枪 | 半自动手枪、全自动步枪、泵动霰弹；原始弹匣/备弹/射速/爆头倍率/衰减 |
| 控制 | 视角相对移动、可调灵敏度、水平 FOV、ADS、冲刺与冷却、跳跃 |
| 敌人 | 巡逻、突击、无人机、精英；感知范围/视场/反应时间、受击硬直、精英扫射打断 |
| 成绩 | 时间/命中/生存原公式，按关卡目标切权重；独立存档，不预填示例成绩 |
| 表现 | 明亮训练园区、原创实体手指/护具/枪械分件、四类机器人、独立弹匣和泵柄 |
| 声音 | 三枪 CC0 采样重新混音，音效/音乐/总音量分离；操作音与简短合成节拍 |

解释原文冲突：霰弹按“一枪至少一颗弹丸命中”统计；评分按 GDD 3.5，s_rank 为练习提示而非额外硬门槛；武器 ADS 以 JSON 为准。FOV 原文未写轴向，这里定义为水平 FOV，默认仍为 95°。

## 测试

从仓库根目录运行：

```powershell
node --test "04 vertex-demo/rebuild/tests/game.test.mjs" "04 vertex-demo/rebuild/tests/full-run.test.mjs"
```

21 项通过。五关模拟玩家通过正常移动/射击/换弹/闸门/撤离完成，未直接修改血量、击杀或通关状态。此测试不等同于真人试玩，也不能证明单局时长或手感评分已达标。

浏览器已验证：加载、兼容模式下实际开火与爆头击杀、暂停、设置保存、三枪静态动作检查。场景连续重建 20 次，GPU 几何/纹理数量前后均为 18/9（该测试环境）。检查时浏览器没有脚本错误日志。

`tests/visual.html` 是不写成绩的画面验收工具，可检查持握/换弹/泵动/瞄准及重建资源；它不是关卡通关证据。

## 仍需真人验收的边界

- 标准鼠标锁定模式尚未在当前自动化环境完成实测；内嵌浏览器拒绝锁定，故保留可玩的窗口兼容模式。
- 自动瞄准模拟玩家约 25–30 秒过关，真人能否达到原案 3–8 分钟节奏尚未校准；不能声称时长已达标。
- 未做真人手感 4/5 评分、标准硬件 1080p 稳定 60fps 测试、主观音质验收。
- 当前是原创程序化 low-poly 动作，不是成熟商业 FPS 的动作资产；没有真人播报、完整称号系统或 Godot 原生包。

## 代码与素材

- `rules.mjs`：评分、弹药、射线/碰撞、路线与分组。
- `game.mjs`：可脱离渲染测试的控制、战斗、AI 和通关状态。
- `view.mjs`：场景、角色、枪械分件和特效。
- `audio.mjs`：Web Audio 采样、混音和操作反馈。
- `app.mjs` / `style.css`：输入、界面、本地成绩与设置。

Three.js 0.180.0 / RoundedBoxGeometry：MIT，许可证在 `vendor/LICENSE`。RoundedBoxGeometry 仅改为本地模块导入。
枪声复用上一版已记录的 Biniou / OpenGameArt CC0 采样，来源及许可见上级 `ASSET-LICENSES.md`。未使用《三角洲行动》或《无畏契约》的专有资产或录音。
